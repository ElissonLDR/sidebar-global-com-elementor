# Sidebar Global com Elementor

**Descrição:**  
Plugin WordPress que exibe um template do Elementor como sidebar em **posts**, **categorias** e **resultados de busca**, com suporte a widgets personalizados (Pesquisa de Blogs e Categorias com contagem).

---

## Funcionalidades

- Adiciona uma sidebar global com template Elementor selecionável.
- Funciona em:
  - Posts individuais
  - Páginas de categorias
  - Resultados de busca
- Widgets Elementor incluídos:
  - Pesquisa de Blogs (pesquisa por título, conteúdo, tags ou frase exata)
  - Lista de Categorias com contagem de posts
- Opção de exibir imagem destacada com border-radius configurável
- Layout responsivo e flexível (70% conteúdo / 30% sidebar)
